Người dùng yêu cầu **phân tích và tư duy trước, code sau** — nêu lại ít nhất 4 lần:
"Phân tích yêu cầu trước khi code" (25/07), "Tư duy rồi mới code" (27/07),
"Bạn cùng tư duy trước khi làm nhé" (25/07), "Tư duy trước rồi đề xuất tính năng
hợp lý rồi mới code" (03/08).

**Vì sao:** người dùng là chuyên gia YHCT, muốn thẩm định hướng giải quyết trước khi
tốn công code sai. Nhảy thẳng vào code thường phải làm lại.

**Áp dụng:** với yêu cầu tính năng mới, trình bày cách hiểu + phương án rồi chờ chốt,
đừng sửa code ngay. Xem [[bang-phuong-an-duyet-mot-lan]].
