**Tiết kiệm token là ràng buộc thường trực**, không phải lời nhắc lịch sự:
"tính toán nhanh ko hết token" (01/08), "tư duy nhanh và sửa nhanh sắp hết token rồi"
(03/08), "Đừng đề tốn token như trước nữa" (08/09), "uỷ quyền cho bạn làm toàn bộ để
đạt mục tiêu và với điều kiện tiết kiệm token nhất" (08/09).

**Áp dụng:** gộp việc theo lô, tránh đọc lại file đã đọc, tránh lặp lại kết quả dài
trong câu trả lời. Khi hết quota thì chuyển sang Ollama — xem [[ollama-khi-het-token]].
